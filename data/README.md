# Evaluation inputs

`evaluation_inputs.json` freezes the inputs before any detector evaluation. It
contains 10 human passages, four AI-generated paragraphs, and four calibration
demonstrations. The first four human passages and all four AI paragraphs form
the score-spread groups; all 10 human passages form the false-positive group.
Calibration rows never increase those group sizes.

The human inputs are public-domain published writing, with author, title,
location, and a primary Project Gutenberg text URL on each row. They include
fiction, first-person prose, and formal scientific/economic nonfiction. They
are not the submitter's own writing. Source edition footnote markers are
retained; whitespace alone is normalized. The `publication_year` field normally
describes the work's original publication, not a claim about a specific
transcription's date. Franklin's linked source is a 1916 English edition
(1922 printing) of the eighteenth-century memoir, using Bigelow's
nineteenth-century text.

Every AI row records `AI-generated by Codex for development` as its origin and
preserves the generation instruction. `ai-03` deliberately repeats a sentence
pattern to exercise stylometry; it is not representative of ordinary AI output.
The edited calibration passage records that Codex performed the edits. Its
results cannot be interpreted as evidence about human editing.

This is a small development sample. Historical prose and generated examples
do not estimate performance for modern writing, multilingual writers, poems,
or an independently authored attack set. Repeating these inputs in three trials
checks consistency; it does not create additional independent samples.


`label_demonstrations.json` is a separate, later reachability set. It retains
Carroll's sourced *Jabberwocky* and explicitly generated rare-vocabulary stress
prose. Neither changes the frozen metric corpus. The unusual generated prose
receives a human-like label, demonstrating evasion rather than correctness.
